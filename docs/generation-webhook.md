# Генерация урока через Make.com

Приложение не вызывает модель само. Оно отправляет задание на вебхук, сценарий
Make генерирует урок и присылает результат обратно. Промпт и выбор модели живут
в Make — их можно менять без правок кода.

## Поток

```
Викладач жмёт «Згенерувати урок»
        │
        ▼
POST GENERATION_WEBHOOK_URL          ← задание + правила + JSON Schema
        │                              (приложение отвечает сразу, status 202)
        ▼
   сценарий Make: AI генерирует урок
        │
        ▼
POST /api/webhooks/lesson            ← готовый урок + одноразовый токен
        │
        ▼
приложение валидирует и сохраняет; страница урока обновляется сама
```

**Почему обратный вызов, а не ответ на тот же запрос.** Генерация занимает
минуты, а вебхук Make обязан ответить за 40 секунд. Синхронный ответ не успеет.

## Что приходит в Make

`Content-Type: application/json`. Размер около 25 КБ — основной объём это
`output_schema`.

```jsonc
{
  "event": "lesson.generate",
  "version": 1,
  "lesson_id": "d329ea23-…",              // вернуть без изменений
  "requested_at": "2026-08-05T10:00:00.000Z",

  "callback": {
    "url": "https://ollielesons.vercel.app/api/webhooks/lesson",
    "token": "одноразовый токен"          // вернуть без изменений
  },

  "input": {
    "title": "Звичайні дроби",
    "grade": "5 клас",
    "topic": "Додавання дробів",
    "theme": "auto",                      // слаг темы | "auto" | "none"
    "generate_spares": true,
    "source_text": "1. Обчисліть 3/4 + 1/4\n2. …"
  },

  "rules": {
    "selection":  ["…"],   // как отбирать задачи
    "difficulty": ["…"],   // нарастание сложности — главное правило
    "variety":    ["…"],   // чередование механик
    "structure":  ["…"],   // порядок блоков
    "timer":      ["…"],   // когда ставить таймер
    "story":      ["…"],   // сюжет и тема оформления
    "spares":     ["…"],   // запасные задания
    "content":    ["…"]    // чего не делать с содержанием задач
  },

  "reference": {
    "themes":       [{ "slug": "space", "label": "Космос" }, …],
    "interactives": [{ "type": "quiz", "description": "…" }, …],
    "block_kinds":  ["intro", "story", "task", "reward", "boss", "final_quiz", "stats", "finish"]
  },

  "output_schema": { … }                  // JSON Schema урока
}
```

`rules` и `output_schema` собираются из кода приложения при каждом запросе.
Их не нужно копировать в сценарий — подставляйте прямо из входящих данных, и
сценарий не разъедется со схемой при её изменении.

## Что вернуть обратно

`POST` на `{{callback.url}}`:

```jsonc
{
  "lesson_id": "{{lesson_id}}",
  "token": "{{callback.token}}",
  "status": "ok",
  "lesson": { … },                        // урок по output_schema
  "meta": {                               // необязательно, попадёт в ai_meta
    "model": "gpt-5",
    "input_tokens": 3200,
    "output_tokens": 11400,
    "cost_usd": 0.28
  }
}
```

Если сгенерировать не удалось:

```jsonc
{
  "lesson_id": "{{lesson_id}}",
  "token": "{{callback.token}}",
  "status": "failed",
  "error": "текст ошибки — покажется викладачу"
}
```

Ответы callback:

| Код | Что значит |
|---|---|
| `200` | Урок принят и сохранён |
| `404` | Неверный токен или задание уже выполнено |
| `422` | Урок не прошёл проверку — в теле `issues` со списком причин |

При `422` урок помечается как `failed`, а причина показывается викладачу.
Список `issues` виден в истории выполнения Make — по нему правится промпт.

## Промпт для модуля AI в Make

> Ниже — вариант в один вызов. Пошаговая сборка сценария из трёх вызовов
> с более дешёвой моделью: [make/scenario.md](make/scenario.md).

Системное сообщение:

```
Ти — методист, який перетворює сирий список задач на готовий інтерактивний урок
для індивідуального заняття з репетитором.

Тобі дають текст із задачами. Твоя робота — не переписати їх усі підряд,
а зібрати з них хороший урок.

ПРАВИЛА ВІДБОРУ
{{join(1.rules.selection; "
")}}

СКЛАДНІСТЬ — НАЙВАЖЛИВІШЕ
{{join(1.rules.difficulty; "
")}}

РІЗНОМАНІТНІСТЬ
{{join(1.rules.variety; "
")}}

СТРУКТУРА УРОКУ
{{join(1.rules.structure; "
")}}

ТАЙМЕР
{{join(1.rules.timer; "
")}}

СЮЖЕТ І ОФОРМЛЕННЯ
{{join(1.rules.story; "
")}}

ЗАПАСНІ ЗАВДАННЯ
{{join(1.rules.spares; "
")}}

РОБОТА ЗІ ЗМІСТОМ
{{join(1.rules.content; "
")}}

ДОСТУПНІ ІНТЕРАКТИВИ
{{join(map(1.reference.interactives; description); "
")}}

Поверни JSON строго за наданою схемою. Нічого, крім JSON.
```

Сообщение пользователя:

```
Назва уроку: {{1.input.title}}
Клас: {{1.input.grade}}
Тема: {{1.input.topic}}
Оформлення: {{1.input.theme}}
Запасні завдання: {{1.input.generate_spares}}

Задачі:
---
{{1.input.source_text}}
---
```

В настройках модуля включите structured output и подставьте
`{{1.output_schema}}` как схему ответа. Схема уже приведена к виду, который
принимают и OpenAI, и Anthropic: `anyOf` вместо `oneOf`,
`additionalProperties: false` на всех объектах.

## Сборка сценария

1. **Webhook** — Custom webhook, скопировать URL в `GENERATION_WEBHOOK_URL`.
2. **Webhook response** сразу после вебхука: код `200`, тело `{"accepted":true}`.
   Без него Make будет держать соединение и приложение получит таймаут.
3. **AI-модуль** — промпт выше.
4. **HTTP → Make a request** — `POST` на `{{1.callback.url}}`, тело из раздела
   «Что вернуть обратно».
5. **Error handler** на AI-модуле — тот же HTTP-запрос со `status: "failed"`,
   иначе при сбое урок навсегда останется в состоянии «генерується».

Чтобы Make определил структуру входящих данных, отправьте ему пробное задание:

```bash
curl -X POST http://localhost:3000/api/dev/generation-sample
```

Маршрут доступен только в разработке. `GET` на него вернёт payload, если нужно
посмотреть глазами.

## Проверки на стороне приложения

Урок отклоняется, если:

- не соответствует `output_schema`;
- ссылки внутри задания не сходятся — `correct_id` нет среди `options`,
  пропуск `{{id}}` объявлен, но отсутствует в тексте, `hp` боса не равен числу
  раундов;
- **сложность падает** — задание легче предыдущего;
- **урок не усложняется** — при трёх и более заданиях последнее не сложнее
  первого, то есть взяты только лёгкие или только сложные.

Последние две проверки — прямая реализация требования «от лёгкого к сложному».
Модель обязана проставить `difficulty` от 1 до 5 каждому заданию; порядок
проверяется автоматически, на слово никто не верит.

## Локальная разработка

Callback должен быть доступен из интернета, а `localhost` — нет. Варианты:

- отлаживать сценарий на продакшене (`ollielesons.vercel.app`);
- поднять туннель: `npx localtunnel --port 3000` и указать его адрес
  в `NEXT_PUBLIC_APP_URL`, чтобы callback вёл на него.

Если `GENERATION_WEBHOOK_URL` не задан, приложение вызывает модель напрямую
через `ANTHROPIC_API_KEY` — запасной путь для работы без Make.
