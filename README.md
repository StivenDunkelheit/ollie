# Ollie

Платформа генерації інтерактивних уроків для репетиторів.

Викладач вставляє задачі текстом — один AI-запит перетворює їх на готовий урок
з інтерактивами, сюжетом і нагородами. Урок проводиться в реальному часі:
викладач керує з Teacher Mode, учень проходить за посиланням без реєстрації.

## Стек

- **Next.js 16** (App Router, TypeScript) — інтерфейс і API
- **Supabase** — Postgres, авторизація викладача, Realtime для синхронізації
- **Claude API** — одна генерація уроку на запит

Окремого WebSocket-сервера немає: синхронізація односпрямована (викладач веде —
учень слідує), тому вистачає Supabase Realtime, а перевірка відповідей живе у
звичайному Route Handler.

## Запуск

```bash
npm install
cp .env.example .env.local   # заповнити ключі
npm run dev
```

### Змінні оточення

| Змінна | Де взяти |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase → Project Settings → Data API |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Supabase → API Keys → Publishable key (`sb_publishable_…`) |
| `SUPABASE_SECRET_KEY` | Supabase → API Keys → Secret key (`sb_secret_…`). Обходить RLS — тільки на сервері |
| `ANTHROPIC_API_KEY` | [platform.claude.com](https://platform.claude.com) → API keys. Потрібен лише для генерації |
| `NEXT_PUBLIC_APP_URL` | Базова адреса застосунку |

### База даних

Supabase → SQL Editor → виконати `supabase/migrations/0001_init.sql`.

Перевірити, що все на місці:

```bash
npm run db:check
```

Для розробки варто вимкнути підтвердження пошти:
Authentication → Providers → Email → Confirm email.

## Розробка без ключів

Урок можна дивитися й проходити, не піднімаючи ні базу, ні AI:

- **`/demo`** — зразковий урок про дроби з усіма шістьма інтерактивами,
  Boss Battle і фінальним квізом. Доступний лише в режимі розробки.
- **Кнопка «Демо-урок»** у списку уроків кладе той самий урок у базу без
  жодної генерації — на ньому зручно тестувати сесії та синхронізацію.

## Ключові рішення

**Схема уроку — один контракт на три ролі.** `LessonSchema` описує структуру
уроку в базі, валідує його перед збереженням і водночас передається моделі як
structured output. Модель фізично не може повернути урок неправильної форми.

**Правильні відповіді не потрапляють у браузер учня.** Публічна версія завдання
збирається з нуля за білим списком полів (`sanitizeInteractive`), а не
вирізанням зайвого — нове приватне поле не витече через забудькуватість.
Перевірка відповіді відбувається лише на сервері.

**Знімок уроку в сесії.** Під час створення сесії урок копіюється в
`content_snapshot`. Редагування уроку не ламає заняття, яке вже йде.

**Клік замість перетягування.** Match, Sort і Drag & Drop керуються кліками:
Student Mode має працювати на планшеті, де HTML5 drag поводиться погано.
